# View to Render

技术路线：Path B — 基于 Rhino 视图的生成式图像转换（2026-11-24 已定）。
输入是 Rhino 导出的固定机位视图，不是直接渲染.3dm 模型。

## Objective

根据用户给定的设计视图，生成新的材质表达效果图。

一句话：当用户提供源视图和目标材质并要求固定机位渲染时，Skill 使用 Muse 图像工具按核对→生成→检查流程输出新 PNG；如果缺少源图或工具不可用，就报告原因而不假装完成。

## Preconditions

1. 确认源视图文件可读取，目标材料要求明确。
2. 识别当前真实可用的图像生成工具和授权。
3. 若无法实际生成图像，停止并报告缺少的能力。

工具：Muse（已验证可调用的生成式图像生成与编辑工具）。
在本对话里出图时，使用 Muse 的图像生成工具，并保存为实际 PNG 文件。

## Required inputs

- 一张固定机位的 Rhino 导出视图（PNG/JPG），例如 `examples/input/source-view.png`。
- 指定目标材料、可变项和必须保留的几何关系。
- 输出位置；未指定时使用项目的 `examples/output/`。

本项目第一张源视图（2026-11-24 已收到）：

- 文件：`examples/input/perspective-01.png`
- 图种：Perspective 透视
- 机位 / 视向：东南侧往西北看，可同时看到东侧 90 m 塔、西侧 81 m 塔、南侧 67 m 塔和中间运动场 / 前广场；此机位已固定，T1 / T2 不换
- 目标材料：日间浅色暖石材立面 + 暖木裙楼 / 庭院墙，玻璃、铺装、绿化、人物

## Workflow

1. 检查源图是否存在且可以读取；记录图像尺寸。
2. 用简洁清单记录相机、建筑轮廓、运动场位置、植物位置等需要保护的可见结构（根据当前输入决定）。
3. 根据用户要求区分允许变化和禁止变化的内容。
4. 使用当前已经确认可调用的图像生成工具进行真实执行。不要把提示词文本当作图像成果。
5. 将生成图像另存为新 PNG，不覆盖原始输入。
6. 打开实际输出；核查目标材料是否变化，并将固定构件的位置、轮廓、连接关系与源图对照。
7. 向用户报告实际保存路径、使用的工具、检查结果、可见偏差与不能确认的内容。

## 任务定义卡（按 W2_0_3jpt.3dm 填写，目标材料待用户确认）

- Goal：把 Rhino 固定机位视图转换成日间材质效果图，表现本项目场地与建筑群。
- Trigger：已有源视图，并要求改变材质或光照表现。
- Exclusions：不用于从零设计三维结构、工程计算或没有源图的纯概念绘图。
- Inputs：必需 source-view.png、目标材质；可选参考材质图、目标分辨率。
- Tools：当前已验证可调用的图像生成工具。
- Fixed（必须保留）：固定视角；场地 810 x 558 m 的范围与底板；中央建筑群的位置与轮廓关系；运动场位置（约 X 295-421 m、Y 241-354 m）；植物大致位置；建筑最高 90 m 的体量关系；每栋楼的层数——最高塔 20 层（Z 10-90 m，每层 4 m），其余塔 13-15 层（每层约 3-4 m），庭院楼 13-14 层。生成时逐栋写明层数，禁止把多层合并成一条大玻璃带；检查时逐栋数层，差 1-2 层以上要记为未通过并重跑。
- Variable（允许改变）：目标建筑 / 地面的材料表现；合理的日间光照与材质氛围；人物活动表现。人物尺度硬规则：人高 1.7 m，约半层高（层高 3-4 m）、约 1/6 裙楼高（裙楼 10 m）、约 1/4 树高（树 6-8 m），长凳高 0.45 m；人物须站稳、脚落在地面上，远近大小要一致，检查时放大看广场、楼底和长凳处的人。树木尺度硬规则：树高 6-8 m，约 2 层高，树冠约 4-5 m，约 4 倍人高；树留在原花坛位置，树冠不得遮住楼和广场，检查时逐棵看。
- Outputs：`examples/output/run-01.png`、run-02.png，保留原始输入。
- Acceptance：实际 PNG 可打开；目标材质改变；固定对象关系无明显漂移。
- Failure：缺输入或工具不可用时，先指出缺项或阻塞，不伪称生成成功。

## Missing input / failure

- 缺少源图或目标材料：先指出缺项，暂不执行。
- 无出图工具或授权失败：报告阻塞，不虚构结果。
- 输出文件不存在或无法打开：标记为未完成。
- 发现重要几何漂移：说明偏差，标记为未通过；若条件允许，修改约束后重新执行。

## Completion

只有实际图像文件可以打开，且已执行上述检查，才可以报告“已完成”。否则标记为“未完成”或“部分完成”，并说明原因。

## 本项目实测信息（2026-11-24，已读文件，未渲染）

- 输入模型：`examples/input/W2_0_3jpt.3dm`，14 MB，单位：米
- 对象总数：4730 个；图层 13 个
- 3D 层：125 个实体（102 个 Brep + 23 个 Extrusion），范围 X 209-541 m、Y 91-396 m、Z 0-90 m
- 场地底板（默认层）：2 个 Brep，范围 810 x 558 m，Z=0
- 曲线层：4541 条 NurbsCurve（多为线稿 / Make2D 类线条，需在 Rhino 里确认）
- Building 层：16 条轮廓线；Sports ground 层：4 条轮廓线，约 X 295-421 m、Y 241-354 m；Plant 层：35 个对象
- 材质：全文件只有 1 个，名为“地图”——没有按材料分好的材质
- 命名视图：0 个；只有默认的 Perspective / Top / Front / Right
- 注意：俯视诊断图是按体块外包框画的，不是渲染图，外包框重叠很多，不能直接当建筑平面来读。真正的形态、机位和固定关系要在 Rhino 里打开确认后，再定 Fixed / Variable。
